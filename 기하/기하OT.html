📌 수행평가 세부 내용

1. 수학적 창의성 기반 문항 설계 평가 (10점 만점 · 10%)

  • 기하 개념을 활용해 스스로 문항을 설계하고 모범 답안(풀이 과정)을 작성하는 활동
  • 평가 요소: 개념 적용의 정확성, 문제 변형의 창의성(단순 변형 vs 복합·융합), 풀이 과정의 논리성
  • 활동지 미제출 시 0점

2. 기하학적 문제해결 과정 구술 발표 평가 (10점 만점 · 10%)

  • 개인 발표: 선생님에게 개별적으로 찾아가 문항을 풀고 설명 → 0.5회 부여

3. 이차곡선과 공간도형 서술 평가 (10점 만점 · 10%)

  • 범위: 이차곡선 ~ 직선·평면의 위치 관계, 삼수선의 정리
  • 문항별 개념 적용, 논리적 서술, 수학적 표기의 정확성을 종합 평가

4. 공간좌표와 벡터 서술 평가 (10점 만점 · 10%)

  • 범위: 정사영 ~ 벡터 전체
  • 문항별 개념 적용, 논리적 서술, 수학적 표기의 정확성을 종합 평가
